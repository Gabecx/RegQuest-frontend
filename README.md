📌 Overview

RegQuest is a web-based credential request and real-time tracking system designed for the Registrar’s Office of the University of Science and Technology of Southern Philippines.

This frontend application is developed using React and Vite to provide an interactive and responsive user interface for students, registrar staff, and administrators. It enables users to submit document requests, track request status, manage requests, and access system services through a centralized web platform.

The frontend communicates with the RegQuest backend through REST APIs, providing a seamless user experience for credential request processing and workload monitoring.
