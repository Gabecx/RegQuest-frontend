RegQuest
RegQuest is a web-based credential request and tracking portal for the University of Science and Technology of Southern Philippines (USTP).

This repository contains the frontend application built with React and Vite, providing an interface for students, registrar staff, and administrators to manage document requests and monitor request status.

Tech Stack

- React.js
- Vite
- Axios
- React Router

Installation

```bash
npm install
npm run dev
